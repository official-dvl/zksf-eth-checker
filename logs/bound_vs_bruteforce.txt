Lean rho(n) = n (log2 log2 n)^2 / sqrt(log2 n) (Asymptotics.lean). With x = log2 n, rho(n) < n iff (log2 x)^4 < x.
integer x from 5 to 69999 where it fails: 5 .. 65536 (all of them); at x = 65536, (log2 x)^4 = 16^4 = 65536 = x.
So with every hidden constant 1, 2^rho(n) >= 2^n for 2^5 <= n <= 2^65536 (2^65536 has 19729 digits).
